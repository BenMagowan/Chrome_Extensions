# Chrome Web Store listings

The text for each solver's store page. The **summary** is each `manifest.json`
`description` (132 characters at most) and ships with the package. The **full
description** is pasted into the Developer Dashboard under Store listing →
Description; the API can't set it.

Both are written to answer the questions people type into the store search, Google
and AI assistants: what it solves, how to use it, what it does with your data, and
whether it's free. Each one leads with a plain sentence naming the game and LinkedIn,
since that sentence is what search snippets and assistants quote.

When the site gets its real name and domain, update the "More puzzles" paragraph in
all five.

## Queens

Summary (123 characters):

```
Solves the daily LinkedIn Queens puzzle for you. Places every queen in one click, or on its own as soon as the board loads.
```

Full description:

```
Queens Puzzle Solver solves the daily Queens game on LinkedIn. It reads the board, works out where every queen goes, and places them for you.

How to use it
1. Pin the extension: click the puzzle piece in Chrome's toolbar, then the pin next to Queens Puzzle Solver.
2. Open today's puzzle at linkedin.com/games/queens and start the round.
3. That's it. Auto-solve is on, so the queens go down as soon as the board appears. If you turn auto-solve off, click the extension's icon and press Solve puzzle instead.

What it does
• Solves every daily Queens puzzle, whatever the board size.
• If you've already started, it clears your wrong queens and X marks and finishes from there.
• Shows a live preview of the board, with its colour regions and any queens already placed.
• You choose how long the solve takes, from 1 to 999 seconds. The default is 5.
• Tells you when today's board is already solved.
• Works whether you're signed in to LinkedIn or playing as a guest.

Privacy
The solving happens in your browser. The extension doesn't collect or send any personal data, and it only works on LinkedIn's game pages, never your feed, messages or profile. Your settings stay on your device.

More puzzles
LinkedIn posts one Queens puzzle a day. If you want more, Puzzle Unlimited has 3,000 free levels of the same puzzle (called Crowns there) on easy, medium and hard, with no login: https://puzzle-site-lyart.vercel.app/crowns

Questions
Is it free? Yes. There's no account or sign-up.
Which browsers does it work in? Chrome on a computer.
Does it solve the puzzle the instant it loads? With auto-solve on, it starts as soon as you press Start and takes about as long as the solve time you've set.

Also from the same developer: Tango Puzzle Solver, Zip Puzzle Solver, Patches Puzzle Solver and Mini Sudoku Puzzle Solver.

Queens Puzzle Solver is an independent extension and isn't affiliated with or endorsed by LinkedIn.
```
